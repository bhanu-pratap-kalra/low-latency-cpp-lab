# low-latency-cpp-lab
A Modern C++ and Linux engineering project focused on designing, implementing, benchmarking, and documenting high performance software components.

The goal of this repository is to build a collection of reusable engineering components while exploring memory management, cache aware programming, concurrency, performance measurement, and systems design through practical implementations.

The project begins with foundational building blocks such as memory pools and gradually evolves into larger components including concurrent queues, networking, protocol parsing, order books, matching engines, and other performance sensitive systems.

Every component follows the same engineering process:

- Understand the problem
- Build a simple and correct implementation
- Add comprehensive tests
- Benchmark and profile
- Optimise where justified
- Document design decisions and trade offs

# Primary Goal

The emphasis is on understanding *why* a design works, not simply producing code.

The repository aims to demonstrate:

- Strong Modern C++ fundamentals
- Careful ownership and object lifetime design
- Linux systems programming
- Cache aware programming
- Concurrent and lock free programming
- Benchmarking, profiling, and performance analysis
- Clear engineering documentation
- Thoughtful design decisions and trade off analysis
- Building reusable components for performance sensitive systems
